Principios

Las cuatro libertades del software libre

Un programa es libre cuando quien lo usa puede ejecutarlo, estudiarlo, copiarlo y mejorarlo. Es la base de GNU/Linux y de buena parte de la infraestructura actual.

Libertad 0

Usar el programa con cualquier propósito.

Libertad 1

Estudiar cómo funciona y adaptarlo a nuestras necesidades.

Libertad 2

Redistribuir copias para ayudar a otros.

Libertad 3

Mejorar el programa y publicar los cambios.

Arquitectura

Máquinas virtuales y contenedores

La diferencia principal es qué se aísla: un equipo completo o solo un proceso.

Máquinas virtuales

  • Emulan hardware mediante un hipervisor (KVM, VirtualBox).
  • Cada una trae su propio sistema operativo.
  • Usan más RAM y disco, y tardan más en arrancar.

Contenedores

  • Aíslan procesos con namespaces y cgroups.
  • Comparten el kernel del host Linux.
  • Arrancan rápido y consumen poco.

Mantenimiento

Automatización con Bash y Cron

Un script de monitoreo, reporte_sistema.sh, registra el estado del servidor servidor-grupo3:

  • Fecha, hora y nombre del host.
  • Usuarios conectados y memoria RAM disponible.
  • Espacio libre en disco y contenedores Docker activos.

Cron lo ejecuta cada 30 minutos.

*/30 * * * * /proyecto/scripts/reporte_sistema.sh
